      Reading AO3 Work Skins on Kindle

      A Work Skin styles a story on the AO3 website. A Kindle reads ebook files, so there are three ways to read your stories there, and each one treats the skin differently. A Work Skin cannot be installed into the Kindle reading interface.

      Read AO3 OnlineUse AO3 itself in a Kindle browser. Nothing is installed on the Kindle.
      1. Open the browser, if your Kindle has one. Some models include an experimental web browser, and availability varies by device.
      2. Visit archiveofourown.org.
      3. Sign in to AO3 if you need to.
      4. Open the story you want to read.
      5. Read it on the AO3 page.

      If a skin is applied and the browser supports the CSS it uses, some of the styling may appear. Support is limited and varies, so fonts, layouts, backgrounds, and custom components may not display correctly. This is not a reliable way to reproduce a complete Work Skin.

      Download the Regular EPUBRead offline with AO3’s standard ebook formatting. The Work Skin is not included.
      1. Open the story on AO3.
      2. Select Download.
      3. Choose EPUB where it is available, and save the file.
      4. Send it to your Kindle with Send to Kindle or another supported method.
      5. Open it from your Kindle library.

      The story can be read offline, but the original Work Skin is not preserved. Copying a CSS file to your Kindle will not change this, because the Kindle cannot apply a separate stylesheet to a book.

      AdvancedCustomize Your Kindle EditionAdapt a Work Skin’s CSS and build it into a downloaded EPUB.

      This is a manual process. You edit the ebook’s internal HTML and CSS, and nothing is converted automatically. Simple typography, colours, borders, and paragraph styles are the easiest to adapt. Complex interface layouts are harder, and not every feature can be reproduced.

      What you need

      • An AO3 story downloaded as an EPUB.
      • The CSS stylesheet of the Work Skin you want.
      • Calibre, installed on a computer.
      • A compatible Kindle device or reading app.
      • Basic familiarity with HTML and CSS, especially for more complex themes.

      Step 1. Download the AO3 story

      Open the story, select Download, choose EPUB, and save the file to your computer.

      Step 2. Download the Work Skin

      Choose a theme from the collection, open its CSS stylesheet, and save a copy. At this point the EPUB and the CSS file are completely separate.

      Step 3. Open the EPUB in Calibre

      1. Open Calibre and add the EPUB to your library.
      2. Select the book and open Edit book.

      The editor lets you inspect and change the chapter HTML files, stylesheets, images, and other resources, and it has a preview so you can check your changes. See Calibre’s Edit Book documentation.

      Step 4. Add the CSS

      1. Look at the existing Styles folder.
      2. Create a new stylesheet or edit an existing one.
      3. Copy the relevant rules from the Work Skin.
      4. Save the stylesheet inside the EPUB.

      Work Skins are written for AO3’s website, not for the HTML inside an EPUB, so do not paste the whole stylesheet without checking what it depends on:

      • AO3-specific containers may not exist in the EPUB.
      • #workskin may need to be replaced with selectors that match the ebook.
      • Custom classes only work if they exist in the downloaded HTML.
      • Some AO3-specific layout rules will not apply.
      • Fonts and decorative images must be added as ebook resources.

      Step 5. Link the stylesheet to the chapters

      Each chapter’s HTML file must reference the stylesheet. This path is only an example. The real path depends on the EPUB’s folder structure.

      <head>
    <link rel="stylesheet"
          type="text/css"
          href="../Styles/custom-skin.css" />
</head>

      Step 6. Adapt the CSS to the ebook

      This step decides how closely your Kindle edition resembles the original. You may need to:

      • Rewrite AO3-specific selectors.
      • Adapt container widths, margins, and padding.
      • Simplify complex layouts.
      • Replace unsupported fonts.
      • Include background or decorative images.
      • Recreate custom chat, notification, or interface components with matching HTML markup.
      • Adjust styles for comfortable ebook reading.

      Step 7. Preview and test

      In Calibre’s preview, check chapter headings, paragraphs, dialogue, spacing, custom formatting, images, page breaks, and font sizes. Make sure the book stays readable when the reader changes the font size or reading settings. Calibre, Kindle Previewer, Kindle e-readers, and Kindle apps can render CSS differently, so test on a real Kindle or Kindle app where you can.

      Step 8. Send it to Kindle

      1. Save the edited EPUB.
      2. Visit amazon.com/sendtokindle.
      3. Upload the EPUB.
      4. Choose your Kindle library or device where the option is offered.
      5. Send the document, then open the book on your Kindle and check how it looks.

      Amazon supports EPUB through Send to Kindle, but the result may differ from the Calibre preview.

      Compatibility warning: customizing an EPUB with an AO3 Work Skin is a manual process. The original stylesheet may need to be rewritten to match the downloaded ebook’s HTML. Some decorative elements and advanced layouts may not work on every Kindle device. Always preview and test your edited EPUB before sending it to Kindle.

      Getting Started

      Found a design you like? Follow these steps to apply an AO3 Work Skin to your own stories.

      1. Choose a design

        Browse the collection and select the theme you want to use.

      2. Preview the layout

        Open the HTML preview to see how the design looks in a browser.

      3. Get the stylesheet

        Open the CSS file and copy its contents.

      4. Create your AO3 Site Skin

        In AO3, go to your Dashboard, select Skins, and open the Site Skins section. Create a new Site Skin and paste the CSS into its CSS field.

      5. Apply the Work Skin

        Save the Site Skin and select it as your active skin. Follow the individual installation guide for any theme-specific formatting classes or limitations.

      Good to know: the HTML files are standalone browser previews. They are not uploaded to AO3. The CSS stylesheet is the part used to create the Site Skin.

      About downloads: a skin only styles a story on AO3 itself. According to AO3’s own guidance, CSS formatting does not carry over into downloaded EPUB, MOBI, PDF or HTML files, so a downloaded copy will appear without the skin. See the Kindle guide for ways around this.
