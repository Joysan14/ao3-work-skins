# A House of Good Men — AO3 Work Skin

A literary, archival-inspired AO3 Work Skin designed for long-form fiction. It combines warm parchment backgrounds, restrained antique accents, classic book typography, and document-style layouts to give a work the atmosphere of a carefully kept manuscript or a collection of private records.

## Design direction

The visual style draws on old books, correspondence, campus archives, newspaper clippings, and institutional documents. It is intended for stories that use varied narrative formats, such as letters, diary entries, messages, reports, transcripts, and newspaper excerpts.

## Included styling elements

The stylesheet includes reusable components for:

- **Opening and chapter headings** — decorative, minimal, and cinematic title treatments.
- **Section dividers and narrative markers** — ornamental breaks, POV labels, flashbacks, memories, time jumps, and location markers.
- **Narrative treatments** — standard prose, drop caps, small-caps leads, monologues, stream-of-consciousness passages, flashbacks, dreams, POV labels, and pull quotes.
- **Personal correspondence** — handwritten-style letter layouts, formal letters, diary entries, and private journal fragments.
- **Digital communication** — email and SMS/iMessage-style message panels, including dark variations.
- **Documents and records** — formal documents, meeting minutes, confidential files, transcripts, and archival-style records.
- **News layouts** — newspaper-style articles, campus news, and editorial treatments.
- **Supporting elements** — author notes, redacted text, small caps, and other inline text treatments.

Several components include alternate variants, including light, dark, formal, archival, urgent, and cinematic treatments.

## Files

- `Fanfic A House of Good Men.html` — a standalone browser preview demonstrating the stylesheet's components. It is for preview/reference and is not uploaded to AO3 as the skin itself.
- `README.md` — this documentation.

If your downloaded stylesheet has a slightly different filename, use the `.css` file included with your copy.

## Installation on Archive of Our Own

1. Sign in to [Archive of Our Own](https://archiveofourown.org/).
2. Open **Dashboard → Skins → My Work Skins**.
3. Select **Create Work Skin**.
4. Enter **A House of Good Men** as the skin title.
5. Open the `.css` file in a text editor and copy its entire contents.
6. Paste the CSS into the Work Skin CSS field.
7. Save the skin.
8. Open one of your works, choose **Edit**, and select **A House of Good Men** in the Work Skin field.
9. Preview the work and check the layout on both desktop and mobile.

## Using the HTML preview

Open the HTML file in a modern web browser to see sample examples of the styling. The preview is a standalone demonstration page. It contains example story text and sample components to illustrate how the classes look.

The HTML preview is not required for installation. AO3 uses the CSS stylesheet together with the HTML you add to your work.

## Notes and compatibility

- The stylesheet is scoped to `#workskin` to reduce interference with the rest of the AO3 interface.
- Responsive rules are included for narrower screens and mobile reading.
- The design uses common system font fallbacks. The exact appearance may vary slightly between devices and operating systems.
- Some decorative or document-style components require the matching HTML structure and class names in your work. Applying the skin alone will not automatically create those elements.
- AO3 may restrict or sanitize certain HTML and CSS features. If a component does not display as expected, check AO3's current Work Skin restrictions and make sure the corresponding markup uses the class names defined in the stylesheet.
